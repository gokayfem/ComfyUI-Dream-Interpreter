# Security and privacy

This package does not collect telemetry, call remote model APIs, or transmit images, interpretations, journal text, or credentials. Runtime browser dependencies are vendored.

Optional journal files are resolved beneath ComfyUI's active output directory; absolute paths and traversal outside that directory are rejected. Creative text outputs are not medical or psychological advice.

Do not publish sensitive dream text or source media in public workflows or issue reports. Use GitHub private vulnerability reporting when available; otherwise contact the maintainer without attaching private data to a public issue.
